# Kept external names

The workbench's public identity is **LS** (`ls-*`); the predecessor is **HS** in prose.
This file is the only exception list for the old spellings. They remain solely as external
contracts, existing host locations, historical source-port inputs, and migration/negative-test data.
The manifest itself necessarily contains those names and is not scanned as ordinary source.

`name_policy.py`, `tests/test_names.py` and `publish-check.sh` read the records below.
Each record is `[repository-relative file, exact literal token, maximum occurrence count, reason]`.
The count includes occurrences in filenames as well as contents. Exceptions are case-sensitive,
file-scoped and counted: a new spelling, file, filename or additional occurrence fails. No subtree,
regex or blanket-name exemption is granted. Binary text and symlink targets are checked too.
Removing a literal need not add another exception. A new external contract requires an explicit review.

## Inventory and migration boundary

The initial inventory at `15a5a99` had **774 matching lines in 90 tracked files** and fourteen
matching paths: ten published skill directories, the port script and its test, and two runtime-name tests.
Published skill directories/frontmatter/references, repository/package/server/CLI names, workbench
settings, internal labels and prose have moved to LS. Existing `hs-*` helper names and `hs_names.py`
remain established short identifiers, not the spelled-out names targeted by this cutover.

Game name selection is centralized in `harness/hs_names.py`. The existing MCP adapter's fixed
external contracts are in `mcp/src/game_literals.py`; this rename does not broaden its game support.
`harness/ls-port.py` separately names its historical source-commit references and preserves its
existing game-branch prefix. `publish.py` owns the explicit live-to-public tables; `cutover.py`
owns the deferred host paths and the shared locks it must never replace.

Main through `8226792` is merged without rewriting its function-map rows or tool changes.
Its three new LS skills are identity entries in the publication map; only the ten older live skills need renaming.
Runtime logs, executables, libraries,
profiles, shader/cache files, port-source filenames, game environment switches and external URLs
keep their exact spelling. Live skill paths, the harness, clone/worktree paths, player/configuration
protection paths and coordination locks still name objects on this PC. No live migration has run.
